# Weather UI — Chapel Hill

A SwiftUI recreation of the iOS Weather application for Chapel Hill, built for iOS Bootcamp Meeting 2.

## 🛠 Features
- **Code Modularity & Subviews:** Refactored layout into modular structs (`HeaderView`, `HourlyForecastCard`, `DailyForecastCard`, `BottomDockView`).
- **Custom Data Models:** Defined weather structs conforming to `Identifiable`.
- **Dynamic Iteration:** Rendered hourly and daily rows dynamically with `ForEach`.
- **UI Elements:** Nested `VStack`, `HStack`, `ZStack`, SF Symbols, and frosted `.ultraThinMaterial` Dynamic Island dock.
